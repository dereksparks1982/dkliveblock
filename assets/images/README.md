# DK Live Block artwork

Put candidate and approved artwork for DK Live Block here. Use transparent PNGs with square 1:1 dimensions for extension icons.

Do not replace or activate an extension icon automatically: select and approve the artwork first. Once approved, export PNG variants at 16, 32, 48, 96, and 128 pixels and update `src/manifest.json` to use the packaged icon files.

Source image assets live in this directory; compiled browser extension images may later be copied to `src/assets/images/` for packaging.
