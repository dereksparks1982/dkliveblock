# ДК Лайв Блок

## ДК Софтворкс · Дом культуры

**ДК Софтворкс** — новое название студии и объединяющий бренд проектов. **ДК** — распространённое в русском языке сокращение от **«Дом культуры»**: места для творчества, искусства, обучения и культурных мероприятий. 

Название студии не изменяет права первоначальных авторов, условия лицензий и исторические сведения об авторстве.


**ДК Лайв Блок** — бесплатное расширение для Файрфокса, которое помогает блокировать рекламу, отслеживающие запросы, нежелательные вкладки и другие навязчивые элементы сайтов. Разработчик: ДК Софтворкс.

**Статус разработки:** Предварительная версия. Удаление рекламных публикаций Фейсбука и совместимость обычных видео Ютуба с блокировщиком требуют проверки в Файрфоксе. Проверка исходного кода сама по себе не доказывает блокировку всей рекламы или соответствие уровню ЮБлок Ориджин. Публичный выпуск пока не утверждён.

**[Официальный сайт и загрузки](https://dereksparks1982.github.io/dkliveblock/?lang=ru)**. Переключатель языка находится в верхней части страницы. Сайт не меняет язык расширения автоматически: его можно выбрать отдельно в настройках самого расширения.


## Возможности

- **Блокировка рекламы и отслеживания.** Встроенный движок с технологиями Гостери и списками фильтров, включая ИзиЛист и ИзиПриватность, блокирует подходящие сетевые запросы. Не все расширенные правила поддерживаются.
- **Очистка страниц.** Косметические фильтры скрывают некоторые рекламные блоки; отдельный инструмент позволяет вручную скрыть элемент до обновления страницы.
- **Специализированные проверки Агент Нести.** Отдельные защитные компоненты выявляют попытки установки куки, нежелательные переходы и признаки рекламы Фейсбука. Не все способы обнаружения работают на каждом сайте.
- **Защита от нежелательных вкладок.** Определяет отдельные виды рекламных переходов и навязчивых всплывающих окон. Обычные ссылки, авторизация и оплата должны оставаться доступными; отдельные случаи могут потребовать исключения.
- **Контроль каждого сайта.** Разрешайте сайты, временно приостанавливайте защиту, управляйте исключениями, правилами и отдельными сетевыми запросами.
- **Прозрачный мониторинг.** Монитор сети и панель сайта показывают заблокированные и разрешённые запросы, найденные правила и доступные причины решений. Можно сохранить локальный диагностический отчёт.
- **Помощь с видео.** Дополнительные инструменты для Ютуба и других потоковых сервисов помогают исследовать рекламные вставки и неполадки воспроизведения; работа зависит от сервиса.
- **Дополнительные возможности.** По выбору пользователя доступны отклонение необязательных куки, скрытие отвлекающих окон, сохранение видео для просмотра позже и дополнительные инструменты для Линукса.

## Управление и конфиденциальность

Откройте значок расширения в панели браузера, чтобы увидеть сведения о текущем сайте, переключить защиту и открыть подробные настройки. Вы можете отменить выбранную блокировку или исключение в любой момент. Переключатель **Русский / English** доступен в интерфейсе расширения.

ДК Лайв Блок **не показывает разрешённую рекламу, не продаёт платные функции и не требует учётной записи**. Нет обязательной телеметрии. Диагностика сохраняется локально; отчёты не отправляются автоматически. Для обновления фильтров браузер может обращаться к поставщикам выбранных списков.

## Установка для тестирования

Расширение пока находится в разработке. Общедоступная версия с подписью Мозиллы ещё не выпущена. Временная установка на компьютере возможна через `about:debugging` → «Этот Файрфокс» → «Загрузить временное дополнение». Выберите файл `src/manifest.json` в распакованном исходном коде. Такая установка обычно действует только до перезапуска браузера. Неподписанный установочный файл не предназначен для постоянной установки в обычном Файрфоксе.

## Конфиденциальность, поддержка и лицензия

Фильтрация выполняется локально. Дополнительные журналы запросов остаются в Файрфоксе, а отчёты экспортируются только по вашему запросу. Для загрузки выбранных списков фильтров расширение обращается к их поставщикам. Подробнее о хранимых данных, разрешениях и сетевых соединениях читайте в [политике конфиденциальности](docs/PRIVACY.md).
