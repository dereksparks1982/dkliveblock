DK Live Block | Orion experiment

Experimental page cleanup only. This package shares DK's existing bounded DOM ad recognizers, including Facebook Sponsored detection.

Not currently included: network request blocking, filter list updates, video response filtering, per-site switches, request inspection, cookie controls, or Linux video downloads.

This is not the full Firefox extension. Orion on iPhone supports only some extension APIs; installation, execution and performance still require a real-device test. If something breaks, disable this experimental extension in Orion's Extensions menu. Orion's own ad blocker should remain off only during a controlled DK comparison.

No telemetry, no outside scripts, no sign-in, no account details collected.
