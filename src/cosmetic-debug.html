Element-hiding inspection

This tool inspects the website tab from which you opened it. It shows matching CSS selectors without collecting page text, URLs, form values, account details or video data. A preview only outlines visible matches. A hidden element remains hidden: this debugger does not temporarily remove the ad blocker's hiding rules.

Press Scan to inspect the original website tab.

My site-specific hiding exceptions

These exceptions stop a selected cosmetic rule from hiding matching elements on this exact website hostname. They do not allow network advertisements or disable other filter lists. You can remove each exception to restore normal hiding.

The first 80 eligible selectors are inspected. Rule origin attribution and deep shadow-root inspection remain future work.
