Privacy: The monitor keeps up to 1,500 recent requests per tab in Firefox memory. It does not collect full URL paths, query strings, request or response bodies, cookies, headers, passwords or IP packet contents. When the limit is reached, older rows are discarded and a warning appears. Export happens only when you click Export CSV.

The number on the DK Live Block toolbar icon counts blocked requests on the current tab independently of whether monitoring is enabled. It resets when the tab navigates or reloads.

Scope: This shows Firefox web requests, not all traffic from your Linux computer. Some browser-internal or cached activity may not appear.
