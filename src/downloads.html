My Downloads

Read-only list of video files in DK Live Block's local Downloads directory. This feature requires the optional Linux companion. No account or network uploads.

~/.local/share/dk-live-block/downloads/

Click Scan My Downloads to check local media.

Only filenames, file sizes and modified dates are displayed. No media files are opened, executed, uploaded or deleted. Partial downloads are intentionally hidden.
