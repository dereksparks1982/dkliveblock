Protection settings

Strict popunder and scam-tab protection

Enabled by default. This stops new tabs opened from these sites even when the destination is blank or uses a constantly changing ad domain. It may also block a legitimate link you intentionally open in another tab. Magnet downloads and normal same-tab navigation are not targeted.

When you actually need a new tab from one of these sites, click DK Live Block's Allow next new tab (15 seconds) button, then open it. Only one new tab is permitted. A scam tab could consume that one-time allowance first, so use this only when needed.

This does not disable Firefox's own popup blocking. Site variants and new attack techniques still require real browser verification.

Advanced browser tools

These options control how you interact with the blocker. They do not reduce blocking coverage. DK Live Block never shows paid promotions, sponsor messages, Acceptable Ads or upgrade nags. There is no marketing switch to hunt down.

The right-click command starts the existing visual element picker on the current website. It never acts on browser-internal or file pages, does not upload page contents, and won't run when DK Live Block is paused. Firefox may ask for context-menu access when installing this development version.

Firefox may ask for additional Developer Tools access when you enable the panel. It stays disabled until you approve the permission and save Settings. Reopen Firefox Developer Tools to show it. This panel displays local, opt-in hostname-level request capture only, without sending browsing data anywhere.

A non-destructive element-hiding debug overlay is still a separate outstanding feature and is not claimed as complete.

Protection-first defaults

Advertising, tracking, cookie-notice, annoyance and social-widget filter lists are enabled for new installations. Explicit cookie rejection and conservative distraction protection are enabled too. There is no Acceptable Ads program or paid protection tier. You may turn individual protections off, and your saved choices are respected. A list only protects you once downloaded; use the status below to check downloads.

Filter subscriptions

YouTube compatibility updates

Data-only YouTube rule packs can update without requiring a new extension version. Downloads come from the DK Live Block public GitHub repository. Firefox add-on updates remain necessary for changes to executable code.

Built-in protection is active. No remote pack installed.

Only simple ad-specific cosmetic selectors are accepted. If a bad update causes problems, roll it back. That version stays disabled until a newer version is published. Remote scripts are never downloaded or executed.

Additional filter lists

Up to five HTTPS subscription URLs, one per line. The list contents are parsed as filter rules, never executed as scripts.

Video and cookies

When enabled, DK Live Block saves your position in ordinary YouTube videos after you've watched at least one minute, and periodically updates it while you watch. It never syncs your viewing history or contacts DK servers. Turn it off to stop new automatic saves; already saved videos remain in your library until you remove them. The library's Erase saved-video history action clears the saved list and last download status, and switches automatic remembering off.

This does not create access to missing articles or unlock server-side subscriptions. Turn this off per preference, or pause DK Live Block on an affected site.

Streaming playback diagnostics

When local request logging is enabled, DK Live Block keeps a short, private record of blocked media and XHR/other requests on YouTube and Disney+. These are potential troubleshooting clues, not evidence that video playback was broken or that the request was legitimate. Blocking advertisements can produce the same records.

Only hostnames, request types, counts and times are retained in memory (up to 60 groups per tab for 30 minutes). No full URLs, paths, cookies, account IDs or raw filter rules. Nothing is uploaded or automatically allowed.

Streaming player health (local)

When private request logging is enabled, DK Live Block also records coarse YouTube and Disney+ HTML5 video-player signals such as sustained buffering (at least five seconds) or media errors. These do not prove that blocking caused the problem. A nearby blocked media request is shown only as a clue, not a confirmed cause. No video title, watch history, timestamps within the video, URL or page contents are collected.

Temporary streaming playback repair

After inspecting a blocked request, you can choose to allow that exact hostname and request type in the current tab for 10 minutes. This may also allow ads. Nothing is allowed automatically, and it does not affect other tabs or all requests to the site.

DK Network Recovery / Open Access

Optional proxy routing for restricted websites and failing images. Off by default. DK Live Block provides no proxy server, VPN or Tor service. A proxy you configure can see network metadata. Nothing is routed automatically without opting in.

One website hostname per line, including its subdomains. Enter domains only, without https:// or paths. Images mode can route image CDN requests made by pages on these sites.

Important: Local Tor must be running before a SOCKS proxy at 127.0.0.1:9050 can work. An incorrectly configured proxy may make selected websites unavailable. Firefox may still attempt direct access after proxy failure; this is not a network kill switch or anonymity protection. These settings cannot bypass every kind of network blocking.

DNS diagnostics

Check a public hostname using Firefox's configured DNS resolver. This does not change your DNS settings. For encrypted DNS, use Firefox Settings → Privacy & Security → DNS over HTTPS.

Failed images and sites

Only failed request hostnames and error categories are kept temporarily in this browser session, never full URLs. A failure does not prove government or ISP blocking. Click to inspect; no automatic proxy routing is applied.

Custom filters

Some ABP syntax is supported. Advanced scriptlets and redirects are not.

Allowed Websites

Allowlist a website if you want DK Live Block to stop blocking there. An entry covers that hostname and its subdomains; every other website remains protected. No ads are allowed globally and there is no paid whitelist.

Advanced: edit allowed hostnames manually

One hostname per line. Manual edits take effect after clicking Save Settings. No URLs or wildcards.

Website repair and exceptions

Review requests you allowed on an individual website and revoke only the permission causing a problem. Revocation restores the normal filtering rules without disabling the whole blocker.

Network Monitor

See requests made by a selected Firefox tab, including what DK blocks, allows or redirects and which requests fail. The toolbar icon's number is your blocked-request count for that tab. Detailed capture is optional, local-only and starts only after you click Start capture.

Private request log

Temporary in-memory log, limited to 250 records per tab. Domain and rule only, not full request URLs.

Statistics

Blocked-request counters are stored locally. Reset removes counts and temporary logs.
