DK Network Recovery / Open Access

Optional proxy routing for restricted websites and failing images. Off by default. DK Live Block provides no proxy server, VPN or Tor service. A proxy you configure can see network metadata. Nothing is routed automatically without opting in.

One website hostname per line, including its subdomains. Enter domains only, without https:// or paths. Images mode can route image CDN requests made by pages on these sites.

Important: Local Tor must be running before a SOCKS proxy at 127.0.0.1:9050 can work. An incorrectly configured proxy may make selected websites unavailable. Firefox may still attempt direct access after proxy failure; this is not a network kill switch or anonymity protection. These settings cannot bypass every kind of network blocking.

DNS diagnostics

Check a public hostname using Firefox's configured DNS resolver. This does not change your DNS settings. For encrypted DNS, use Firefox Settings → Privacy & Security → DNS over HTTPS.

Failed images and sites

Only failed request hostnames and error categories are kept temporarily in this browser session, never full URLs. A failure does not prove government or ISP blocking. Click to inspect; no automatic proxy routing is applied.

Website repair and exceptions

Review requests you allowed on an individual website and revoke only the permission causing a problem. Revocation restores the normal filtering rules without disabling the whole blocker.
