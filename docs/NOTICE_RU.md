# Информация для пользователей из России

**ДК Лайв Блок** (DK Live Block) — бесплатное расширение для Firefox, разработанное **Elderred Softworks LLC**. Оно предназначено для блокировки рекламы, отслеживающих запросов и навязчивых элементов сайтов, а также для управления исключениями.

## Как работает защита

- Фильтрация выполняется в браузере. Для обычного использования не требуется учётная запись.
- Настройки, списки пользовательских правил и выбранная диагностика хранятся локально. Разработчик не получает автоматически историю посещений, содержимое страниц, пароли, cookie или отчёты.
- Для обновления встроенных и выбранных списков фильтров браузер обращается к сторонним поставщикам. Эти сайты могут видеть технические данные соединения, в том числе IP-адрес. Дополнительные сведения приведены в [политике конфиденциальности](PRIVACY.md).
- Сообщения об ошибках через электронную почту или GitHub отправляются **только по инициативе пользователя**. Не включайте в обращения пароли, токены, приватные ссылки и другие конфиденциальные сведения.

## Прокси и ограничения доступа

В дополнительных настройках Firefox есть **необязательная маршрутизация через прокси, который пользователь указывает самостоятельно**. По умолчанию она выключена. ДК Лайв Блок **не предоставляет VPN, прокси-сервер или сервис Tor** и не гарантирует доступ к ресурсам, ограниченным провайдером или государством. При использовании стороннего прокси его оператор может получать технические сведения о соединениях; отдельные запросы также могут проходить напрямую, поэтому эта функция не обеспечивает анонимность.

Расширение само по себе не определяет гражданство или местонахождение пользователя и не меняет уровень защиты из-за выбора русского языка.
