# Build 143: recognize Google Ad Manager slots in normal websites

Unreleased v0.3.113. Some ad containers served through Google Ad Manager carry `data-google-query-id` rather than generic ad classes. The independent DOM recognizer now treats that explicitly ad-specific attribute as a strong signal, alongside existing AdSense and GPT markers, with conservative checks before hiding. The page mutation observer also watches the attribute so dynamically filled ad slots are detected. Unrelated `data-query-id` attributes are not affected, and ordinary articles, forms, identity dialogs and media players retain the protected-element safety gate. Regression coverage includes new and dynamic slots and reversible styling. Full Firefox and offline suite acceptance is still required.
