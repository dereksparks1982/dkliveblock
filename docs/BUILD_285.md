# Build 285 / v0.3.255: Nesty evidence-to-strategy review integration

**Date:** November 2, 2026. **Branch:** `main`. **Scope:** shared intelligence coordinator and safety-contract tests only; no new blocking policy, permissions or UI geometry.

## Implemented
The existing `src/nesty-intelligence.js` coordinator previously linked bounded signal vocabulary, company routing, provider observation and passive dispatcher matches but did not hand its conclusions to identifiable, testable countermeasure reviews. Build 285 adds `planReviews`, which translates only recognized signal combinations into immutable strategy review records with a stable `id`, an accountable owner, exact platform, bounded evidence tokens, `stage`, `enabled:false` and `executable:false`.

Proposals cover Facebook sponsored post cards, Facebook Sponsored rail, **disabled experimental** Facebook GraphQL ad-response handling, YouTube ad-break evidence routed to existing YouTube engines (not a fictional new Nesty specialist), and source-linked unwanted navigation owned by Nesty Popup Guard. Sibling Meta apps remain observation-only and never inherit Facebook strategies. If a protected context is present, no review strategies are proposed. Read-only private intelligence snapshots now report `selfLearning:false`, `automaticRules:false` and browser-verification requirements.

## Regression contracts
Four additional tests in the *already registered* `tests/nesty-integrity-build282.test.js` assert named plan ownership, immutability, no execution, disabled GraphQL, no Meta platform leakage, protected-context veto, rejected private/unrecognized tokens, lookalike origin rejection and truthful status reporting. The changes were JavaScript syntax-checked and the isolated coordinator was evaluated in V8 against the actual unmodified company/team/catalog/provider/dispatcher modules before committing. No claim of a complete Ubuntu suite pass or live browser acceptance is made before verification.

## Unchanged
Firefox native and bundled Ghostery engine, existing YouTube/Disney+ response filtering, Meta DOM ad-removal policy, GraphQL default off, permissions, three approved Agent Nesty names, eleven historical methods, owner-approved bilingual art/layout, local privacy, optional proxy behavior and country access.

## Still required
Complete latest Ubuntu regression; protect owner-observed working sites; measure fast Facebook scroll/rail flashes and false positives in real Firefox; gain evidence for reviewed strategies and explicit approval before permitting actions; expand independently tested Meta platform adapters; finish proper evidence-to-response lifecycle and assess adaptive model accuracy. Original release audit still requires an authentic `package-lock.json`, reproducible vendor build, signed Mozilla acceptance and owner authorization. **This build does not claim completed integration or uBlock parity.**
