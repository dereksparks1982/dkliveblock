# Build 131: enforce signed-link safety in both URL cleanup engines

Unreleased 0.3.101. The independent filter engine gained whole-URL protection for signature and session parameters, but Firefox's separate built-in privacy helper still recognized a smaller key set. As a result, an URL with `utm_signature` could be left alone by the engine and then rewritten by the built-in tracker cleaner, invalidating a signed link. Both layers now recognize UTM-prefixed signature, token, nonce, state, authentication, session and expiry markers along with additional cloud signing fields. They conservatively decline to rewrite the entire link, preserving checkout/download/login functionality. Cross-layer tests assert both helpers skip the same signed URLs while ordinary news tracking tags remain removable. Full local and Firefox acceptance pending, no Actions or release.
