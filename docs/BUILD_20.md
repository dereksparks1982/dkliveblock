# DK Live Block Build 20: 0.2.1 (source development)

Unreleased. No Firefox Add-ons distribution or YouTube reliability claim.

The embedded Ghostery 2.20.3 engine is present in the source tree, with MPL 2.0 notices. Build 20 improves single-listener rule arbitration, prevents broad network rules from closing tabs, preserves local exceptions and protects YouTube Skip Ad controls. The data-only YouTube compatibility pack is upgraded to version 2 with ad-labeled mobile and desktop slots.

The offline regression suite can establish that these implementation details behave as expected. Live Firefox YouTube preroll/midroll blocking and Disney+ playback compatibility remain untested. No premature release packages.
