# Build 138: restore only CSS modifications we still own

Unreleased 0.3.108. The content script tracks original inline display values when it hides a sponsored container. Previously, disabling the filter always restored that stored value, even if the site had deliberately changed the element's style in the meantime. That could undo a newer site choice or affect a control. The restore path now changes an element only if it is still hidden with the extension's `display:none!important` marker; otherwise it leaves the live style alone. When the original declaration was absent, it removes the property rather than applying an empty string. The regression test executes the actual source restoration function with an isolated style fixture. Full Firefox and Ubuntu acceptance remains pending; no external dependency or Actions.
