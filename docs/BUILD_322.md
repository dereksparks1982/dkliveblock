# Build 322: dynamic YouTube A/B result localization

Source v0.3.292, unreleased. English/Russian switching previously translated static controls and exact dynamic messages, but generated A/B summaries concatenated English phrases and enum codes into unmatched strings. The lab now translates fixed display fragments, metric labels, warnings, and manually classified outcomes before composing user-visible text, and re-renders them when the saved interface language changes. Exported comparison JSON remains unchanged, English-schema and privacy-projected. This build does not recolor or move the existing UI, change requested hostnames, player behavior, filter code, telemetry or extension permissions. Five source tests registered; native Ubuntu and Russian visual/accessibility QA pending.
