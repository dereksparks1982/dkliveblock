# Build 70: opt-in combined current-tab diagnostics

Version 0.3.40, unreleased. The user requested a consolidated blocked and permitted report across websites. This build adds two voluntary Site Dashboard buttons for TXT and JSON export of up to 25 current HTTP(S) tabs across Firefox windows. Each snapshot is retrieved by the extension, verified against the still-open tab's hostname, and fed to the existing sanitized blocked and permitted exporters. Tab titles, full URLs, paths, cookies, form content, credentials and query parameters are excluded. The explicit confirmation warns that even hostnames can reveal browsing. Skips closed/changed tabs and does not automatically enable logging or perform external research. No permissions or Actions. Offline execution/browser acceptance pending. Not a YouTube ad fix.
