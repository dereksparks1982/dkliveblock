Install for testing in Firefox

For a temporary developer installation of the source ZIP in Firefox:

  1. Download the source ZIP from Google Drive and extract it.
  2. In Firefox, visit about:debugging.
  3. Choose This Firefox and Load Temporary Add-on.
  4. Open the extracted folder, then choose src/manifest.json.
  5. Use the DK Live Block toolbar icon to inspect blocking and adjust optional settings. A separate filtering engine download is not required.

This is a temporary Firefox developer install; it normally ends on browser restart. The source ZIP is not a signed XPI. An unsigned XPI test package is available separately, but it is not a permanently installable release.

Download options

Google Drive: Download source ZIP or Download Firefox XPI (unsigned test). The GitHub repository is a separate destination for browsing the project source.

Unsigned test package: The Firefox XPI has not been signed by Mozilla and cannot be installed permanently in regular Firefox. It is provided for developer testing, not as a verified public release. The source ZIP can be used for the temporary Firefox developer installation described above.
