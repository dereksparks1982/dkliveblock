What it does

Block ads and trackers

Bundled native and Ghostery-based filtering with EasyList/EasyPrivacy subscriptions, plus cosmetic cleanup. No Acceptable Ads program and no paid feature gates.

Stop unwanted popups

Controls for intrusive new tabs, advertising redirects and page clutter. Site-specific exceptions help preserve ordinary links and sign-ins.

Inspect and control requests

Review blocked and permitted traffic, see rule evidence where available, export privacy-conscious TXT/JSON diagnostics and toggle eligible site-scoped requests.

Choose what stays

Pause or allowlist a website, manage site exceptions and use temporary Block Element hiding. Optional cookie rejection and distraction cleanup are configurable.

Development and site-test status

Current repository source: Build 260, version 0.3.230 (November 1, 2026). DK Live Block is still in development: it is not a signed Firefox Add-ons release, and independent feature parity with uBlock Origin or Adblock Plus has not been established.

Observed behavior in Firefox: In specific owner tests, DK Live Block suppressed ads on YouTube and Disney+, while also blocking intrusive popups on tested websites. These observations are not a guarantee of universal ad removal or playback compatibility.

Provisional: CBS News playback is currently working after repairs; a longer repeat test is pending. Known FAIL / retest pending: Owner screenshots show Facebook sponsored feed posts and right-rail ads surviving earlier builds. Recent builds improved feed-post detection using explicit sponsorship evidence; live Firefox acceptance is still pending.

Ad Investigator: The optional, draggable, Firefox-local tool explains advertising evidence, displays a bounded DOM hierarchy and possible cosmetic-rule matches, and opens the existing network log, rule details and individual Allow/Block controls. The synthetic model does not automatically install new filters, and CSS matches alone do not prove blocking.

Other sites, long-session performance, advanced filter compatibility, privacy/security reviews and Mozilla signing remain release gates. See the browser test notes and roadmap for details.

Install for testing in Firefox

To try the latest development source in desktop Firefox:

  1. Get the current source from the GitHub repository (Code → Download ZIP), extract it, or update your existing local checkout. The separate Google Drive ZIP may be an older test upload.
  2. In Firefox, visit about:debugging.
  3. Choose This Firefox and Load Temporary Add-on.
  4. Open the extracted folder, then choose src/manifest.json.
  5. Use the DK Live Block toolbar icon to inspect blocking and adjust optional settings. A separate filtering engine download is not required.

This is a temporary Firefox developer installation; it normally ends when Firefox restarts. The source ZIP is not a signed XPI. The separate unsigned XPI is intended for development testing, not permanent installation in standard Firefox.

Download options

Development uploads on Google Drive: Source ZIP and unsigned Firefox XPI. The GitHub repository is the reference for the latest committed source.

Important: GitHub source commits do not automatically refresh those Google Drive uploads, which may not match the current repository source. Check the src/manifest.json version before testing. Public download access for the XPI has not been independently verified. It is unsigned by Mozilla and cannot be installed permanently in regular Firefox; there is no approved public release yet.
